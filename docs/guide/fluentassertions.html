01 · Overview

Expressive Result assertions

Resultron is the core library for modeling success and failure outcomes. Resultron.FluentAssertions is a separate package intended to integrate Result testing with FluentAssertions.

Install the integration package in your test project. Keep the core package in your application project, and add the integration where you write assertions.

02 · Installation

Install the integration package

From the directory containing your test project, run:

Terminal
dotnet add package Resultron.FluentAssertions

If your test project does not already reference the core library and FluentAssertions, add the dependencies required by your project as well.

03 · Usage

Use it in your test project

Reference the package in the test project, then use the assertion extensions supplied by the installed package to express the expected state of a Result or Result<T>.

The exact assertion method names and supported result types should match the API exposed by the version you have installed. See the package documentation and examples in the repository for the current API.
