Quick Start

Add Resultron to your project and model expected application outcomes with a clear Result flow.

01 · Install

Add the package

Terminal
dotnet add package Resultron
02 · Create

Return a typed result

Represent the outcome directly instead of throwing for expected domain or validation failures.

UserService.cs
Result<User> result = CreateUser();
03 · Match

Handle both outcomes

UsersController.cs
return result.Match(
    success => Ok(success),
    failure => BadRequest(failure.Errors)
);
